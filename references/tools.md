# 麦当劳 MCP 工具速查（本项目用到）

> 提取自麦当劳中国官方 MCP 文档 `M-China/mcd-mcp-server`。完整说明以官方仓库为准。

## 门店与餐品

### query-nearby-stores — 查询附近门店
- 入参：用户提供的城市或地址（从用户输入中获取）
- 返回：附近的麦当劳餐厅列表（含门店标识，供后续点餐/查券使用）

### query-meals — 查询当前门店可售卖餐品列表
- 入参：门店标识（来自 query-nearby-stores / 用户指定）
- 返回：菜单（分类、餐品编码、标签等），用于点餐选品

### query-meal-detail — 查询餐品详情
- 入参：餐品编码
- 返回：套餐组成、默认选择等

## 优惠券

### query-store-coupons — 查询当前门店可用券
- 入参：门店标识
- 返回：该门店下用户可使用的优惠券列表

### available-coupons — 麦麦省券列表查询
- 入参：无
- 返回：用户当前可领取的麦麦省优惠券列表

### auto-bind-coupons — 麦麦省一键领券
- 入参：无（自动领取用户可领的所有券）
- 返回：领取结果

### query-my-coupons — 我的优惠券查询
- 入参：无
- 返回：账户下所有可用优惠券列表

## 计价

### calculate-price — 商品价格计算
- 入参：门店信息、就餐方式、商品列表（可含优惠券）
- 返回：商品金额、配送费、优惠金额、应付总价

## 辅助

### now-time-info — 获取当前时间信息
- 入参：无
- 返回：当前完整时间，便于判断营业/活动时段

---

## 接入约束
- MCP Server 地址：`https://mcp.mcd.cn`
- 鉴权：`Authorization: Bearer <你的 MCP Token>`
- 协议：Streamable HTTP；仅支持 MCP 2025-06-18 及之前版本
- 限流：每个 Token 每分钟最多 600 次请求，超限返回 429
